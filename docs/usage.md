# 手机使用说明

移动 Web 复用电脑上已有的 DS Bot 团队、会话、输入框和消息组件。电脑需要保持运行，手机浏览器需要能访问当前 DSH 入口并完成登录。首次安装见[安装教程](installation.md)，网络入口配置见[远程访问](remote-access.md)。

v0.1.4 增加了账户菜单中的“手机访问”。扫码和复制链接都使用宿主官方认证；不需要另外配对原生 App 或 bridge。

## 第一次在手机上打开

### 在电脑取得登录链接

1. 在电脑本机打开已登录的 DS Bot，点击左下角账户按钮。
2. 在“用量、连接器、Bot 设置”所在菜单中选择“手机访问”。
3. 面板会检查入口。若显示电脑本机地址或尚未设置，填写已配置且受宿主信任的 HTTPS 地址，点击“保存并检查”。完整配置见[远程访问](remote-access.md)。
4. 看到“登录入口已就绪”后，用手机相机扫码，在浏览器中打开；也可以点“复制登录链接”，通过自己的设备同步方式传给手机。
5. 复制被浏览器拒绝时，展开“手动复制登录链接”，选中内容后复制。关闭弹窗会清理界面里的链接。
6. 手机完成登录后，打开一个已有 Bot 或群聊。电脑和 DSH 需要保持运行。

“修改地址”可更新保存的入口。“刷新入口”重新读取当前宿主的官方登录链接，并不承诺撤销旧链接或重新生成独立凭据。宿主重启后再打开面板获取。远程手机页面不能签发其他设备的登录链接，需要回电脑本机操作。

不要把二维码当成一个普通的网址图片。它携带登录权限，公开分享可能让其他人进入你的 DSH。不要把链接粘进 Issue、终端输出或公开截图；排错时只报告去掉查询参数的入口类型和错误文字。

如果二维码或复制操作不可用，先保留错误提示，查看[故障排查](troubleshooting.md)。不建议自己拼接带 token 的链接，也不要把某个本机私有插件路径当作所有安装都具备的登录入口。

### 可达地址与登录链接有什么区别

可达地址负责把手机请求送到电脑，例如你配置的私网入口。官方签名登录链接在此基础上让 DSH 验证当前访问请求。即使普通地址能打开，手机也可能仍未登录。

手机看到 `authentication required` 时，说明该次请求已经到达 DSH 宿主，但手机浏览器没有可用的认证会话。回到电脑，通过宿主已有的官方方式在“手机访问”面板刷新入口，再在实际使用的手机浏览器扫码登录。反复刷新普通域名通常不能解决认证缺失，不建议先清空全部 cookie。

`127.0.0.1`、`localhost` 在手机上指手机自身。不要把电脑打印的本机签名 URL 手动换成另一台设备的 IP 或域名；应让宿主按已经配置的手机入口生成链接。网络方案可以是可互通的局域网、私网或已有的认证代理，具体操作见[远程访问](remote-access.md)。使用 Tailscale 时，两端都需要按该方案连入相应私网；插件本身不会创建隧道。

登录状态属于当前浏览器及访问入口。手机换浏览器、使用无痕窗口、清理站点数据，或者改用另一个入口后，可能需要重新登录。主机重启后入口或会话是否仍有效，也应以当前页面状态为准，不要一直使用旧二维码。

## 会话列表与聊天

手机列表会显示现有 Bot 和群聊，并使用它们的精灵。点击一项进入对应的原版会话；聊天标题保留精灵与连接状态。搜索框用于筛选列表。

底部的“聊天”“团队”“连接”用于切换手机页面。进入聊天后，底栏收起，为正文和输入框留出空间；左上角返回会话列表。

聊天输入、附件入口、流式回复、工具和交互卡片仍由原 DSH／DS Bot 处理。布局插件不会新建第二份消息历史，也不会因为回前台而自动重发消息。某种卡片或附件是否可用，还取决于当前宿主的功能、权限和浏览器支持。

第一次使用可以按下面的顺序确认：

1. 打开一个已有会话，检查名称和近期内容是否正确。
2. 输入一条你确实想发的短消息，点击发送，等待原版会话给出结果。
3. 返回列表，再进入同一会话，确认能继续查看。
4. 只有在宿主实际出现问答或审批卡片时再处理，先读清选项内容。

网络中断或发送结果不明确时，不要连续点发送。先观察原版会话里的状态，等连接恢复后检查是否已经收到回复，避免把不确定的发送结果当作失败而重复提交。

## 连接状态与恢复

手机界面会显示连接状态。“连接”页提供同步和重新连接操作。网络恢复后先同步现有会话；只有连接确实不能恢复时再尝试重新连接。

电脑休眠、DSH 退出、网络切换或手机浏览器挂起，都会影响实际可用性。页面里暂时保留的消息不代表电脑还在线；界面显示已连接也不能单独证明刚提交的消息已经处理完成，要结合会话中的结果判断。

手机从后台回来后，先给页面时间恢复，再查看新消息。若持续停在旧内容，手动同步或刷新。刷新前保留尚未确认送达的草稿；不要假定所有浏览器都会保存未发送内容。若出现认证提示，重新从电脑生成官方登录链接。

Safari 的软键盘、安全区、锁屏和长时间后台行为仍需真机验证。遇到输入框被挡或无法恢复时，可以先收起键盘、调整方向或切回原版布局，并按[排错文档](troubleshooting.md)记录复现条件。

## 切换原版与手机布局

聊天页右上角的“原版”可切回原布局；关闭手机布局后，页面提供“手机布局”按钮，可再次开启。也可在 DSH 插件设置页打开“手机布局”，调整“启用手机布局”。

这两个入口使用同一个布局偏好，保存在当前浏览器。电脑与手机、Safari 与其他浏览器之间不会自动同步；浏览器禁止站点存储时，选择可能只在当前页面有效。

关闭页面内开关只改变这个浏览器的布局选择。若要停用插件本身，在 DSH 插件管理器停用 `dsh-mobile-layout-local` bundle，再刷新。桌面宽屏按原桌面布局显示；缩窄电脑窗口也可能触发手机布局。

## 升级与回退

升级在运行 DSH 的电脑上完成，手机只需在升级后刷新。先保留旧版包和校验值，再按[安装教程](installation.md#回滚)使用官方管理器升级。

出现布局冲突时，先用“原版”恢复当前浏览器的布局。需要整套环境恢复时，停用新增 bundle 并刷新。不要为此删除 DS Bot、团队、群聊或已有会话。

第三方插件若自己注册了精灵形状，手机里可能无法显示完全相同的形状。本插件构建时打包的精灵 registry 与第三方运行时 registry 不一定共享；内置精灵、头像图片和颜色的支持范围不能推导为所有自定义形状都兼容。

# 手机使用指南

完成[安装和扫码登录](installation.md)后，手机与电脑共用原有 Bot、群聊和消息历史。保持电脑唤醒、DSH 运行，并连接可访问电脑的网络。

## 打开和切换会话

“聊天”查看会话列表，“团队”查找 Bot，“连接”查看当前连接状态。搜索框按名称筛选；点开 Bot 或群聊后使用左上角返回。

聊天沿用宿主的消息和输入组件。群聊发言者、流式回复、工具结果及交互卡片是否可用，取决于当前 DS Bot 和宿主能力。右上角可打开当前会话详情。

## 日间与夜间外观（0.4.6）

主页左上角的月亮按钮切到夜间，太阳按钮切到日间；按钮说明始终表示下一次点击的目标。会话内左上角仍用于返回列表，连接设置从底部“连接”打开。

外观与宿主的外观设置共用同一项偏好，刷新后保持选择。初始“跟随系统”会随设备亮暗变化；点击按钮后会选择明确的日间或夜间。若要恢复跟随系统，在宿主外观设置中选择系统主题。

支持的浏览器从按钮位置展开新配色，其他浏览器短暂过渡颜色；系统开启减少动态效果时立即切换。网页加载层在宿主外观偏好解析后与页面一致。在此之前，以及 iPhone 系统显示静态桌面启动图片时，亮暗由操作系统决定。

## 主屏幕状态栏（0.4.14）

手机顶部的时间、电量区域随页面主题配色。启动文档直接声明透明状态栏，独立的安全区背景避免系统边缘模糊覆盖标题。页面使用完整布局高度消除底部多余留白；键盘展开时继续跟随可视区域，底部保留必要的手势安全区。

升级后先刷新页面，再从多任务界面完全关闭桌面 Web，重新点图标打开。iOS 可能保留旧入口的外观资料；若仍使用旧白色顶栏，用 Safari 打开普通入口后重新添加主屏幕图标。先保留原入口并确认新入口登录正常；重新添加的入口可能需要重新登录。不要清除网站数据。

## 输入和发送

输入文字后点发送按钮，或按宿主支持的 Enter 快捷键。手机布局中，有效消息开始提交时会收起输入键盘；无需等模型回复。Shift+Enter 换行，空消息和不可发送状态不会触发收键盘。桌面宽屏仍保留输入焦点。

附件、草稿、发送回执和连接恢复继续由宿主处理。页面不会在恢复前台时自行重发一条草稿。如果发送结果不确定，先查看会话中是否已有该消息，再决定下一步，避免手动重复发送。

## 添加到手机桌面

先在常用浏览器中完成登录，再添加入口。

### iPhone / iPad

1. 用 Safari 打开已登录的普通入口地址。
2. 点分享按钮，选择“添加到主屏幕”；未显示时在分享菜单中向下查找。
3. 确认名称后添加。以后可从桌面图标打开。

### Android

1. 用 Chrome 打开已登录入口。
2. 打开浏览器菜单，选择“添加到主屏幕”；具体名称因系统和浏览器而异。
3. 按提示添加快捷方式。

桌面入口的显示方式、窗口和登录存储由浏览器决定。它不提供离线聊天保证，也不会让电脑在关机后继续运行。若桌面入口重新要求登录，在该入口里完成登录；必要时重新从电脑取得登录链接。

## 为什么再次打开还会加载

当前页面短期保留最近会话，来回切换通常可以复用已加载历史。刷新、系统回收页面、长时间后台或超出保留窗口后，浏览器仍需重新连接并加载。

页面加载完成后会在空闲时准备基础资源缓存，后续打开可以复用。首次下载、电脑连接和聊天历史仍需网络，系统也可能清理缓存。遇到慢启动时，先确认私网已连接、电脑未休眠，再区分“打开整个页面慢”还是“进入某个长会话慢”。详见[常见问题](faq.md)和[故障排查](troubleshooting.md)。

## 登录与连接

日常可收藏普通 HTTPS 地址。登录过期、换浏览器或改用另一地址后，可能需要重新扫码。电脑本机账户菜单的 **手机访问 → Web** 可以刷新登录入口。

使用 Tailscale 时，手机离开 Wi-Fi 后仍需保持 Tailscale 已连接。网络恢复后先等待宿主恢复，再确认会话状态；不要连续重装或清空浏览器数据。

## 更新与退出

更新在电脑插件管理器完成，手机刷新即可。要撤下移动界面，在电脑停用 Mobile Web；不要删除 DS Bot 或团队。

登录二维码和完整登录链接只给自己的设备。关闭二维码面板会清理该面板内容，不代表撤销已经建立的浏览器会话。

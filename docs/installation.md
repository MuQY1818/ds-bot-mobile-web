# 安装与连接

Mobile Web 安装在电脑的 DSH 中。手机只需浏览器，无需安装插件包或原生 App。

## 开始前

- 电脑已经运行 DSH 和 DS Bot，原有团队能正常使用。当前适配组合为 DSH `0.2.1-rc.2` / DS Bot `0.1.7`。
- 手机能访问电脑的 HTTPS 入口。使用 Tailscale 等私网时，两端均需连入对应网络。
- 安装到你日常使用的同一个 DSH 环境，沿用现有团队，不另建第二套运行环境。

## 第一步：安装插件

1. 在电脑打开 [Releases](https://github.com/MuQY1818/ds-bot-mobile-web/releases)，下载 `ds-bot-mobile-web-0.4.3.tgz`。
2. 打开现有 DSH 的官方插件管理器，选择本地包安装，选中刚下载的文件。
3. 确认名称为 `ds-bot-mobile-web`，完成安装后启用并刷新原页面。宿主提示重启时，按提示重启同一个环境。

不要把 `.tgz` 解压后传到手机。GitHub 的 “Source code” 压缩包供开发使用，不是插件安装包。

## 第二步：准备访问入口

电脑与 DSH 需要保持运行。若已经有手机可用的 HTTPS 地址，直接使用；尚未准备时，按[网络连接](remote-access.md)配置。Tailscale 是可选的私网方案，插件不会替你安装网络工具、开公网或改域名。

电脑上的 `localhost` 和 `127.0.0.1` 不能直接给手机使用，它们在手机上表示手机自己。不要手工替换登录链接中的域名，应先配置入口，再让宿主为该入口生成登录链接。

## 第三步：扫码登录

1. 在电脑 DS Bot 左下角账户菜单选择 **手机访问 → Web**。
2. 确认入口就绪。需要填写时输入已准备好的普通 HTTPS 地址，再点“保存并检查”。
3. 用手机相机扫码，或将“复制登录链接”得到的链接私密发给自己的手机。
4. 在目标浏览器完成登录，打开一个已有 Bot 或群聊。以后可收藏普通入口地址，或[添加到手机桌面](usage.md#添加到手机桌面)。

二维码只用于 Web 浏览器登录。App 标签的二维码用于原生设备配对，两者不能互换。扫码入口应从已登录的电脑页面取得。

## 升级

在电脑下载新版 `.tgz`，通过同一插件管理器更新，按提示启用或重启，再刷新手机页面。保留旧版安装包，便于回退。正常更新不需要删除团队、清空会话或重装 DS Bot。

安装被依赖发布时间策略拦住时，先看错误中的包名并等待允许安装；不要通过删除锁文件或全局关闭策略解决一个布局插件的更新。

## 回滚

要暂时恢复桌面原布局，在官方插件管理器停用 `ds-bot-mobile-web` 并刷新。需要退回旧版时，再通过管理器安装保留的旧包。只处理 Mobile Web；原 DS Bot、团队和会话保留。

## 从旧包名迁移

旧包名为 `dsh-mobile-layout-local`。先停用旧包，再安装并启用 `ds-bot-mobile-web`，刷新后检查手机访问入口。确认新版正常后可移除已停用的旧包。

如果升级后入口未就绪，维护者可检查配置中是否仍引用旧模块名。保留原行 ID 和 `phoneUrl`，只把模块名改为新包名：

```yaml
- id: mobile-layout-local
  name: ds-bot-mobile-web
  config:
    phoneUrl: https://dsh.example.com/
```

示例域名需换成你已有的地址。普通用户不必为正常安装手动编辑配置。遇到问题先看[故障排查](troubleshooting.md)。

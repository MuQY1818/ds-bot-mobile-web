# 0.4.14：iPhone 主屏幕布局验证版本

用户在正式安装后确认顶部仍模糊，因此未发布 GitHub Release；0.4.15 候选继续处理该问题。

本版整合 0.4.12 的透明状态栏和 PNG 图标，处理 iPhone 主屏幕 Web 的底部多余留白、顶部标题模糊，以及消息操作栏遮挡下一条消息；顶部效果未通过后续真机重开验收。

根画布使用 `100lvh`，让初始可视视口少算状态栏高度时，布局仍能覆盖完整屏幕。键盘展开继续由原有 VisualViewport 跟随处理。状态栏安全区在应用挂载前，直接从页面根部绘制主题背景；消息操作栏为触摸悬停、焦点和展开菜单留足空间。

在现有 DSH 插件管理器安装并启用 `ds-bot-mobile-web-0.4.14.tgz`，再刷新手机页面。旧主屏图标可能保留安装时的状态栏和图标资料；需要重新添加时先保留原入口并确认新入口可登录，不要清除网站数据。

本版不包含连接传输优化。反复拉取大型会话目录与网络唤起延迟仍需独立处理。验证范围见[验证记录](../validation.md#v0414主屏幕布局)。

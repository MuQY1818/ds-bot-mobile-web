# 0.4.15 候选：iOS 27 顶部清晰度

0.4.14 的安全区背景未能阻止 iOS 27 的原生边缘模糊覆盖标题。0.4.15 将 iPhone 主屏幕 Web 的标题、头像和按钮放在这段区域下方；保留随主题变化的背景，以及已经修正的底部高度。

兼容空间仅在 iPhone／iPod 独立 Web App 且 Safari Version 为 27 时生效。iOS 27 的 User-Agent 可能将 OS 字段固定为 18.x，因此不能用 OS 字段判断。额外空间最多 24 CSS px，顶部安全区为零时也为零。

收起键盘后，WebKit 还可能持续报告 `visualViewport.offsetTop = -59`。独立 Web 的固定区域已经包含这段原生偏移；0.4.15 不再将负值重复应用到页头和底部导航，正向键盘偏移仍保留。

本版处于候选验证阶段，尚未发布正式 GitHub Release。模拟器使用真实 DSH / DS Bot 和本插件，并复现了旧版问题；验证详情见[记录](../validation.md#v0415ios27顶部兼容)。不将模拟器结果当作用户 iPhone 最终验收。

更新现有插件后刷新页面并重开原主屏幕入口，不需要清除聊天、登录信息或网站数据。本版没有改变连接传输或会话请求逻辑。

# 0.4.8：主屏幕 Web 状态栏主题

iPhone 从主屏幕打开 Web 后，页面已经切换到夜间，顶部时间、电量区域却仍为白色。此前移动界面只处理了页面组件配色，没有给系统浏览器提供同步的主题颜色与画布外观。

本版在应用代码之前安装轻量外观适配：`theme-color`、`color-scheme`、iOS 自适应状态栏样式与根画布颜色跟随宿主日夜偏好。视口提前覆盖安全区，既有顶部内边距继续避开系统状态栏。手机布局关闭、切回宽屏或插件卸载时，适配会还原原来的 metadata 和根样式。Manifest、入口身份、登录和会话缓存不变。

升级在电脑插件管理器中完成。手机刷新后从多任务界面关闭主屏幕 Web，再重新打开。若 iOS 仍保留旧入口外观，可按[使用指南](../usage.md#主屏幕状态栏048)保留旧入口并重新添加、确认新入口登录。不需要清除网站数据。

验证范围：Node 自动检查、WebKit 窄视口外观与清理检查，以及 iOS 26.5 模拟器中现有主屏幕图标打开后的日间 → 夜间 → 日间。模拟器使用隔离页面加载本版实际外观模块与移动样式，确认顶部背景和系统图标变化；这不代表用户 iPhone 真机已验收。打包、安装与宿主集成记录见[验证页](../validation.md)。

# 0.4.7：长会话样式计算优化

移动样式原先有 22 处 class 片段选择器，覆盖 9 类宿主 class。在长聊天发生样式失效时，这些规则增加了样式匹配成本。本版从已加载的同源宿主样式表中查找精确类名，以 `:is(...)` 保留原选择器权重；未知片段继续使用原规则。

编译只读取样式表，不扫描聊天 DOM。监听范围限定在 `head` 内的样式变化和样式链接加载，80 ms 合并更新；结果相同时不重写样式。停用时取消任务、断开监听并移除本插件的样式。未修改宿主代码、消息协议或滚动位置处理。

隔离 Chromium、390px 视口、一段约 12,000 字符的合成回复、约 763 个 DOM 节点中，交错六轮的 350 次受控样式失效与布局读取，原规则耗时约 381–414 ms，精确类名规则约 55–64 ms，匹配元素和几何读值相同。这是样式微基准，不能解释为真机滑动帧率提高七倍，也不代表所有滚动卡顿均已消除。

详细工程检查、浏览器交互与设备边界见[验证记录](../validation.md)；性能背景见[性能记录](../network-performance.md)。

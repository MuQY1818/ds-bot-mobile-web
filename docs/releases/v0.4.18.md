# 0.4.18

适配 DS Bot 0.2 的界面结构，修复手机上的三处布局问题（#4）。

DS Bot 0.2 把电脑端左侧栏和 Windows 标题栏按钮挂到页面最外层，原有的侧栏隐藏规则管不到它们，左侧栏会在手机上盖住会话列表。0.2 还会给宿主中间栏注入一段左边距，为左侧栏留位置；左侧栏隐藏后，会话页左侧会空出一条。此外，0.2 的触屏样式把消息操作栏（表情、回复、更多）往右贴，再加上本插件原有的贴左规则，操作栏被撑成整行白条。

0.4.18 在移动布局下隐藏这两个外层元素，清除注入的左边距，并让操作栏恢复为消息下方的一排图标。电脑端布局不受影响。

160 项自动检查通过，其中 3 项是本次新增的回归检查；8 项安装包生命周期检查在 DSH `0.2.1-rc.2` / DS Bot `0.1.7` 组合下通过。DSH `0.2.1-rc.5` / 官方 DS Bot `0.2.6` 组合已在实际宿主上安装，用户在 iPhone 上确认了修复效果。

从发布页下载 `ds-bot-mobile-web-0.4.18.tgz`，在电脑端 DSH 插件管理器中安装并启用。

# 0.4.6 候选

主页左上角现在可以切换日间与夜间。月亮切到夜间，太阳切到日间；连接设置仍位于底部“连接”，聊天内左上角仍返回会话列表。

精灵沿用原版亮暗调色、眼睛与高光；主 Bot 的橙色星标和群头像保持在各自位置，不再因原 Bot 界面样式撤回而变黑或溢出。

外观使用宿主的同一项持久偏好，刷新后保持选择。浏览器支持时，新配色从按钮位置进行 300 ms 圆形展开；其他浏览器采用 200 ms 色彩过渡，开启减少动态效果时立即切换。需要恢复跟随系统时，在宿主外观设置中选择系统主题。

加载层在宿主已解析外观后遵循明确的亮暗选择。系统静态启动图与偏好解析前的加载阶段仍由操作系统亮暗决定。此候选已通过隔离 Chromium 和 WebKit 检查，尚未发布、安装到实际宿主或验证 iPhone 真机。

Adds a persistent sun/moon theme toggle using the host theme service. Supported browsers reveal the new palette from the button over 300 ms; other browsers use a 200 ms color transition, and reduced motion switches immediately. Connection and chat-back navigation retain their roles. This is a tested candidate, not a published or production-installed release.

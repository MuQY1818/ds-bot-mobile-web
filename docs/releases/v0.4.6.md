# 0.4.6

主页左上角现在可以切换日间与夜间。月亮切到夜间，太阳切到日间；连接设置仍位于底部“连接”，聊天内左上角仍返回会话列表。

精灵沿用原版亮暗调色、眼睛与高光；主 Bot 的橙色星标和群头像保持在各自位置，不再因原 Bot 界面样式撤回而变黑或溢出。

外观使用宿主的同一项持久偏好，刷新后保持选择。浏览器支持时，新配色从按钮位置进行 300 ms 圆形展开；其他浏览器采用 200 ms 色彩过渡，开启减少动态效果时立即切换。需要恢复跟随系统时，在宿主外观设置中选择系统主题。

加载层在宿主已解析外观后遵循明确的亮暗选择。系统静态启动图与偏好解析前的加载阶段仍由操作系统亮暗决定。

125 项工程检查、Chromium / WebKit 实际渲染和八项精确包生命周期检查通过。已安装到实际宿主并确认手机入口、加载层和 Worker 正常，其他插件与 Bridge 身份保留。本轮没有完成 iPhone 真机主题交互自动验收。

Adds a persistent sun/moon theme toggle using the host theme service. Supported browsers reveal the new palette from the button over 300 ms; other browsers use a 200 ms color transition, and reduced motion switches immediately. Mascots retain their canonical colors even without the original Bot surface styles. Installed and verified on the local host; physical iPhone theme interaction remains unverified.

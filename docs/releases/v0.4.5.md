# 0.4.5

为常见 iPhone 桌面入口增加亮暗主题启动图，并把页面内的加载动画改为独立页面层，等手机界面就绪后淡出。保留已有代码缓存、近期会话预热和发送后的键盘过渡。

iOS 启动图是系统显示的静态图片；这次修改改善等待反馈，不承诺系统唤起或网络耗时已消除。无需重建团队、清空会话或更改现有连接。

Adds light and dark iPhone launch images and an independent loading layer that fades when the mobile interface is ready. Existing code caching and keyboard transitions remain. The system launch image is static; it does not remove network or operating-system startup time.

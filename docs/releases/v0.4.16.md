# 0.4.16

手机 Web 从后台或短暂断网恢复时，保留近期会话并自动恢复电脑连接，减少重新加载和手动重新连接。

- 取消后台 30 秒主动清理近期会话，保留最近 3 项、5 分钟的内存上限。
- 短暂切换复用健康连接；较长后台和网络恢复时自动重连，并合并重复恢复。
- 为读取增加超时，挂起的旧请求不会永久卡住后续同步。
- 保留草稿与有效登录；恢复不自动重发消息。403 访问拒绝不再提示为登录过期。

桌面上安装新版插件后刷新手机页面即可。日常使用普通 HTTPS 地址；无需把启动 token 当成长久书签。宿主默认登录有效期为 30 天，可按[常见问题](../faq.md)设置为一年，新有效期在下次正常登录签发时生效。

已通过自动检查、独立真实 DSH + mock 模型的 WebKit 恢复测试，以及独立宿主重启后的 cookie 保留测试。浏览器测试使用模拟的可见性事件和断网，没有在用户真实会话发送消息。iOS 系统可以挂起或回收 Web 页面，本版提供前台恢复，不能阻止系统回收。

# 0.4.17 候选版

修正移动 Web 把部分连接恢复故障直接提示为「登录已失效」的问题。

团队状态读取返回 401 后，页面先用原有登录核验受保护首页。登录仍有效时，自动重试一次状态读取；接口仍未恢复时请求重连，保留近期会话引用。首页也拒绝登录时仍提示重新验证，核验期间断网则显示网络错误。

检查不更换 token，不自动登录，也不重发消息。原有登录有效期、权限校验、后台恢复与缓存上限保持不变。

已在 iOS 27 主屏幕 Web App 的隔离环境中验证网络中断、后台返回、原图标重开，以及注入 401 的修复前后对照。用户手机上最初的持续失效尚未直接复现，本版不宣称已排除所有 VPN 或系统凭据问题。

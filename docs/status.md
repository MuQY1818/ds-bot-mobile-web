# 当前状态

更新日期：2026-10-19。Web 是目前主要的手机访问方式。

## 已可使用

已发布的 **0.4.5** 已通过正式插件管理器安装到实际宿主，现有 HTTPS 私网入口可用，原团队、会话及 Bridge 设备身份保留。适配组合为 DSH `0.2.1-rc.2` / DS Bot `0.1.7`。

- 手机会话列表、团队搜索、单聊与群聊导航。
- 复用原版消息、输入框、流式回复和宿主支持的交互卡片。
- 电脑端 **手机访问 → Web** 登录二维码，与 App 共用弹窗。
- 手机有效发送后收起输入键盘。
- 基础资源及固定版本插件代码缓存、独立加载动画、iPhone 桌面启动图与空闲时近期会话预热。
- 手机外层页面锁定，聊天、设置与多行输入保持各自滚动。
- 当前页面内的最近会话短期保留，以及减少重复团队同步。

## 正在完善

- 首次下载、脚本解析与连接恢复仍可能耗时；后续启动可复用资源。
- iPhone Safari 的真实边界回弹手感，仍需在设备上继续确认。
- iPhone Safari 长后台、锁屏、网络切换和更多输入法组合。

上述优化未完成前，不承诺离线使用、页面被系统回收后仍保持全部缓存，或每次打开立即完成加载。

## Web 与 App

Web 用户安装一个 Web 插件即可。原生 App 仍是独立源码预览，当前版本为 App `0.1.4`；本轮没有把尚在验证的文字选择候选当作已交付功能。详情见 [App 状态](https://github.com/MuQY1818/ds-bot-mobile-app/blob/main/docs/status.md)。

安装与操作见[安装指南](installation.md)和[使用指南](usage.md)。开发者需要的隔离测试、性能测量与已覆盖范围保留在[验证记录](validation.md)和[性能记录](network-performance.md)。

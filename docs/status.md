## 2026-10-18 配置迁移修复

旧包 `dsh-mobile-layout-local` 改名后，已有 profile 的 `mobile-layout-local` 配置行可能仍带旧的 `name`。这会让新包忽略旧配置，手机访问回退到本机地址，并显示“手机入口尚未就绪”。

修复是只把该行 `name` 更新为 `ds-bot-mobile-web`，保留 `phoneUrl` 和行 ID，再通过正式管理器重新加载该插件。部署复核已确认状态恢复 `ready`，HTTPS 登录链接可完成认证，未登录入口仍拒绝访问。具体配置见[迁移步骤](installation.md#从旧包名迁移)。

本次未更换网络域名、关闭认证、重置团队或重新创建设备配对。

## 与 App 的边界

Web 的二维码用于 DSH 浏览器登录；原生 App 需要独立 Bridge 的设备配对资料。两种二维码不可互换。原生 App 仍处于源码预览，状态见 [App 开发状态](https://github.com/MuQY1818/ds-bot-mobile-app/blob/main/docs/status.md)。

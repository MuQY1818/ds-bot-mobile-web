# 验证范围

契约测试使用固定上游DS Bot通道、公开npm Cordis/Connection与隔离业务fixture；覆盖列表、Bot/群文本提交、群进度、归属、只读、路由卸载、取消、未知响应和会话订阅生命周期。

前端控制器测试覆盖导航、过期请求、并发刷新、恢复不重发、401提示、释放及列表字段投影。浏览器组合使用原版renderer/composer和mock模型，验证正文增量、群归属、离线保留草稿、恢复无额外prompt、多个手机视口和滚动。

0.1.1的精灵状态和动态效果按版本变更记录另行验收；不能拿字母占位旧包或静态截图证明动画。尊重prefers-reduced-motion和上游motion偏好。

未保证：iPhone Safari实际软键盘、安全区、锁屏与长后台；已接受但ACK丢失的语义去重；附件/审批/密钥卡全组合逐项验证；升级DSH后的所有DOM兼容。恢复时没有新增自动提交逻辑，原版错误和草稿行为继续生效。

仓库不包含运行home、浏览器登录材料、用户聊天、截图录屏或生产profile。构建和单测不需要真实模型密钥。
